# PhenyoSync Warehouse Management System

A warehouse management system designed to improve inventory tracking, reduce stock loss, and support logistics operations for a fresh produce business.

## Features
- Inventory tracking
- Product management
- Logistics coordination
- Data-driven decision support

## Technologies
- Angular
- ASP.NET MVC
- SQL Server
